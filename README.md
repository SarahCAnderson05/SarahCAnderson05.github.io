# Sarah Anderson Personal Site

A free, minimal personal website starter for GitHub Pages.

## Files

- `index.html` — homepage
- `me.html` — about page
- `work.html` — research/projects page
- `notes.html` — notes index
- `notes/first-note.html` — example note
- `photos.html` — photo placeholder page
- `uses.html` — tools/gear page
- `style.css` — all styling

## What to edit first

1. Replace `YOUR_EMAIL_HERE` in `me.html`.
2. Add your LinkedIn and GitHub links.
3. Replace photo placeholders in `photos.html` with real images.
4. Add your resume PDF and link it from `work.html`.
5. Update the project descriptions with exact details and photos.

## How to publish on GitHub Pages

1. Create a GitHub account if you do not have one.
2. Create a new public repository named `YOURUSERNAME.github.io`.
3. Upload these files to that repository.
4. Go to Settings → Pages.
5. Under Build and deployment, publish from the `main` branch and `/root` folder.
6. Your site should appear at `https://YOURUSERNAME.github.io`.
